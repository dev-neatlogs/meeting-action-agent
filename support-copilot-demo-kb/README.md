# support-copilot-demo-kb

Static help-center fixture used by the NeatLogs `support-copilot` flagship demo.
Pages are intentionally fabricated. Hosted on GitHub Pages from `/docs` on `main`.

URL: https://neatlogs.github.io/support-copilot-demo-kb/

Refund policy versioning:

- `refund-policy-v2.1.html` — archived (30 days; superseded March 4, 2026)
- `refund-policy-v3.0.html` — current (30 days; aligned with the public FAQ)

The pre-triage demo seeds Chroma without v3.0 to manufacture a probabilistic regression.
The triaged demo uses the full seed so retrieval returns the current policy.
